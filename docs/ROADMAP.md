# 전체 로드맵

## 0. 설계 ✅

- ✅ 아키텍처 결정 ([ARCHITECTURE.md](ARCHITECTURE.md))
- ✅ 모노레포 폴더 구조
- ✅ DB 설계 ([DATABASE.md](DATABASE.md))
- ✅ API 설계 ([API.md](API.md))

## 1. 개발 환경

- ⬜ `infra/docker-compose.dev.yml`: 로컬 PostgreSQL
- ⬜ `backend/`: Spring Boot 프로젝트 생성 (Java 21, Gradle, JPA, Security, Flyway, Validation, springdoc)
- ⬜ `frontend/`: Next.js 프로젝트 생성 (App Router, TypeScript, Tailwind), 프로토타입의 디자인 토큰과 컴포넌트 옮기기
- ⬜ GitHub Actions에 백엔드·프론트 테스트 추가

## 2. 백엔드 기반

- ⬜ 공통: 예외 처리, 에러 응답, 페이지 응답, Auditing
- ⬜ Flyway V1: 전체 테이블 생성
- ⬜ 테스트 기반: Testcontainers(PostgreSQL)로 통합 테스트

## 3. 핵심 기능 (순서대로)

1. ⬜ **상품 조회**: 카테고리, 목록, 필터, 정렬, 상세 + 시드 데이터(프로토타입 상품 32개 이전)
2. ⬜ **회원**: 이메일 가입·로그인, JWT 쿠키, 내 정보, 배송지
3. ⬜ **소셜 로그인**: 카카오, 네이버 (각 개발자 콘솔에 앱 등록 필요)
4. ⬜ **장바구니, 위시리스트**: 비회원 장바구니 합치기 포함
5. ⬜ **주문**: 금액 계산, 쿠폰, 주문 생성, 만료 스케줄러
6. ⬜ **결제**: PG 결정 → 테스트 키로 승인, 실패, 취소, 웹훅
7. ⬜ **리뷰**
8. ⬜ **반품·교환**

## 4. 프론트엔드

- ⬜ 손님 화면: 메인, 목록, 상세, 장바구니, 주문서, 결제 결과, 마이페이지, 로그인
- ⬜ API 클라이언트: OpenAPI 스펙으로 타입 자동 생성
- ⬜ SEO: 메타 태그, OG 이미지, 상품 JSON-LD, sitemap.xml

## 5. 관리자 화면 `/admin`

- ⬜ 대시보드
- ⬜ 상품 등록·수정 (이미지 업로드, 옵션·재고)
- ⬜ 주문 처리 (상태 변경, 송장 입력, 취소·환불, CSV 내보내기)
- ⬜ 반품·교환 처리
- ⬜ 배너, 공지, 쿠폰, 설정
- ⬜ 👤 친구분과 같이 써보고 불편한 점 고치기

## 6. 인프라, 배포

- ⬜ 💳 카페24 VPS 신청 (Ubuntu, 메모리 4GB 이상 권장: Spring + Next.js + PostgreSQL)
- ⬜ 서버 기본 보안: SSH 키 로그인, 방화벽(22, 80, 443만), 자동 보안 업데이트
- ⬜ `infra/docker-compose.yml` + Nginx + Let's Encrypt HTTPS
- ⬜ 💳 Cloudflare R2 버킷 (이미지, DB 백업)
- ⬜ GitHub Actions: 이미지 빌드 → GHCR → SSH 배포
- ⬜ DB 매일 백업 (pg_dump → R2), 복구 연습 한 번
- ⬜ 모니터링: 헬스체크 알림(UptimeRobot 등), 에러 로그

## 7. 사업·법적 준비 (개발과 병행) 👤

- ⬜ 사업자등록 (홈택스)
- ⬜ 💳 도메인 구매, DNS 연결
- ⬜ PG 가입·심사 → 받은 키로 운영 결제 설정
- ⬜ 통신판매업 신고 (구매안전서비스 확인증 필요: PG사에서 발급)
- ⬜ 이용약관, 개인정보처리방침, 교환·반품 정책 작성
- ⬜ 사이트 하단에 사업자 정보 표시 (상호, 대표자, 사업자번호, 통신판매업 번호, 주소, 연락처)

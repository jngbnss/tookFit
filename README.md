# T.O.O.K FIT — Storefront Demo

A responsive, accessible frontend e-commerce demo for **T.O.O.K FIT**, a modern Korean-inspired men’s fall/winter label.

**Live demo:** https://jngbnss.github.io/tookFit/

> **Frontend-only demonstration.** No real payments, orders, inventory, or accounts are processed. Authentication and payment are simulated in the browser and offer no production security. Use sample information only.

## Features

- **Home** — announcement bar, sticky header, editorial hero, New Arrivals, Best Sellers, seasonal banner, Shop by Category, brand statement, newsletter (simulated), recently viewed.
- **Catalog** — 11 collections (New Arrivals, Best Sellers, 8 categories, Sale), search with suggestions and recent searches, combined category/size/color/price/in-stock filters, four sort orders, results count, reset, Load More, no-results state, quick add, wishlist toggle. Filters live in the URL (`#/shop/outerwear?size=M&sort=price-asc`).
- **Product details** — gallery with thumbnails and enlarge dialog, color/size/quantity selectors with inline validation, variant-level stock, sold-out variants disabled, max 5 per variant, size guide dialog, Add to Bag, Buy Now, wishlist, Web Share API with copy-link fallback, accordions for fit/materials/care/shipping, related products, JSON-LD product data.
- **Wishlist** — persistent, move-to-bag, empty state, header count.
- **Bag** — drawer and full page, quantity controls, remove, clear with confirmation, coupon, free-shipping progress, recommendations, header count.
- **Checkout** — two-column desktop / single-column mobile, validated shipping form, card / Kakao Pay / Naver Pay simulation, processing, decline, retry, and success states.
- **Orders** — confirmation page, order history, order detail, empty state.
- **Account (simulated)** — sign in, create account, forgot password, dashboard, sign out.
- **Info pages** — About, Shipping & Returns, Size Guide, Contact, FAQ, Privacy, Terms, 404.
- **Local analytics abstraction** — `track()` records events (`product_view`, `search`, `filter_applied`, `wishlist_add`, `add_to_cart`, `checkout_start`, `payment_success`…) in localStorage only. Nothing is transmitted.

## Tech stack

React 19 · Vite · TypeScript · React Router (HashRouter) · plain CSS with design tokens · Vitest · React Testing Library. No UI or state libraries.

```
src/
  domain/     typed models (Product, CartItem, Order…) — swap mocks for real APIs behind these
  data/       product catalog (32 products)
  lib/        pricing, catalog filtering, validation, mock payment, storage adapter, analytics
  state/      store provider (cart, wishlist, auth, orders, recent items, toasts)
  components/ layout, dialogs/drawers with focus trap, product card, purchase panel…
  pages/      routes (lazy-loaded)
  test/       unit and integration tests
```

## Local development

```bash
npm install
npm run dev        # http://localhost:5173
```

## Tests

```bash
npm test -- --run
```

Covers cart quantities and variant separation, totals, coupon cap, shipping threshold, cart/wishlist/login persistence, combined search + filters, sorting, no-results, required variant selection, stock and max-quantity limits, checkout validation, card success and decline, Kakao Pay flow, order creation, cart clearing, non-persistence of card data, and smoke tests for every route.

## Production build

```bash
npm run build      # outputs dist/ with base /tookFit/
npm run preview
```

## Deployment (GitHub Pages)

`.github/workflows/deploy.yml` runs on every push and pull request: `npm ci` → tests → build. On `main` it uploads `dist` and deploys with the official Pages actions to the `github-pages` environment, with a concurrency group to avoid overlapping deployments. Pages source must be set to **GitHub Actions** (Settings → Pages).

## Demo data

| What | Value |
| --- | --- |
| Successful card | `4242 4242 4242 4242`, any future expiry (e.g. `12/30`), any 3-digit CVC |
| Declined card | `4000 0000 0000 0002` |
| Other cards | Any Luhn-valid 16-digit number succeeds |
| Coupon | `TOOK10` — 10% off merchandise, max ₩20,000 |
| Shipping | ₩3,000; free at ₩100,000+ merchandise subtotal (before coupon) |

Prices are in KRW and include VAT. Card number, expiry, and CVC exist only in component state during checkout; orders store at most the last four digits.

## Images

Product and editorial images in `public/images/` are **original, procedurally drawn studio illustrations** generated by `scripts/generate_images.py` (Pillow). They are not photographs, not AI-generated, and contain no third-party assets, logos, or trademarks. Regenerate with `npm run images`. Replacing them with an AI-generated or photographed campaign is the remaining asset task — keep filenames (`<slug>-01.webp`, `<slug>-02.webp`, 4:5, WebP) and the app picks them up automatically.

Visual direction was informed by public storefronts for mood only; no code, copy, or assets were copied.
